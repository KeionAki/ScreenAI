  1. 点下方「下载证书描述文件」，在弹窗中选「允许」。
  2. 打开「设置」，顶部会出现「已下载描述文件」，点进去选「安装」。
  3. 进入「设置 › 通用 › 关于本机 › 证书信任设置」，打开「ScreenAI Local CA」的完全信任开关。
  4. 回到本页点「我已完成，重试连接」。
